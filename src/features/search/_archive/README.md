# Search archive

`SearchScreen.tsx` was the placeholder screen of the former "Recherche" tab, removed on 2026-11-01
when the tab bar was aligned with the validated mockups (4 tabs for individuals, 5 with "Publier" for professionals).

Search currently lives on the Home screen (SearchBar + SearchOverlay). The future advanced search
will be opened from there, not from a tab. Nothing in the app imports this file; do not import it in new code.
